Giới thiệu về tôi

Đây là nội dung trang web gốc do chính mình tự tay thiết kế từ đầu. Bạn có thể tự do viết bất cứ điều gì bạn thích vào các khối này để giới thiệu về bản thân hoặc sở thích.

Dự án cuối khóa

Trang web này đã áp dụng đầy đủ các kỹ thuật nâng cao bao gồm: Liên kết bỏ qua (Skip link), Thanh điều hướng tùy chỉnh, Hệ thống lưới Grid Layout và Mô hình hộp Box Model chuẩn chỉnh.
